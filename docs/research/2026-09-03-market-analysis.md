## 2. 게임별 심층 분석

### 2.1 메이플 키우기 (넥슨코리아·에이블게임즈, 2025-11)

**기본 정보**
- Unity 클라이언트, .NET 서버. 원작 2D 도트 리소스 그대로 쓰는 횡스크롤. 이동·점프만 수동, 전투 자동.
- 성과: 출시 2개월 300만 유저. 국내 월매출 2026-01 439억 원, 02월 391억 원(양대 마켓 1위). 2026-08 3주 구글 매출 2위.
- 사건: 어빌리티 최고 옵션이 약 1개월간 아예 등장하지 않던 확률 오류 → 2026-01-28 출시 이후 전 결제금액 조건 없는 전액 환불(넥슨 최초).

**코어 루프**
- 1캐릭터 + 메인 동료(30초마다 소환) vs 몬스터 **무리**. 47개 챕터 × 10~20 스테이지. 1~9는 웨이브+미니보스, 10은 단일 보스 타임어택.
- 오프라인 사냥 분당 51마리(멤버십 76마리).
- 재화 9종 이상: 메소, 레드 다이아(무기·동료 소환), 블루 다이아(현금), 월드보스 코인, 몬스터 포인트, 아머 스톤, 주문의 흔적, 명예의 훈장, 용사의 증표.
- 영구 성장: 레벨(스탯 포인트), 어빌리티(무한 리롤), 무기 각성 5성, 동료 메인 1+서브 8, 유물 합성·각성.

**직업·전직**: 14직업(모험가 12 + 시그너스 2). **10Lv 1차 → 30Lv 2차 → 60Lv 3차 → 100Lv 4차**. 전직 퀘스트는 형식상. 무과금도 일일 루틴으로 30일 내 3차 전직. 영웅 수집은 동료 가챠. 누적 소환 횟수 자체가 마일스톤 보상 축(소환 패스 9종).

**아이템·장비**
- 무기 + 방어구 9부위 + 보스 전용 부위(반지·목걸이·귀걸이·얼굴장식·눈장식·포켓·투구).
- 등급 노말/레어/에픽/유니크/레전드리. 강화 3중(주문서·스타포스 30성·잠재옵션).
- 드롭: 일반 방어구는 스테이지 드롭이 아니라 '엘리트 몬스터 소환'(몬스터 포인트) → 잡템 분해 → 아머 스톤 → 소환 레벨업. **보스별 부위 고정 드롭**: 킹슬라임(반지), 알리샤르(목걸이), 파파픽시(얼굴장식), 자쿰(얼굴장식·투구), 혼테일(귀걸이·목걸이), 핑크빈(포켓·눈장식).

**펫·수집**: 펫·포획·몬스터 도감 없음. 동료 가챠와 유물이 대체.

**리텐션**: 성장 던전 5종(일일 3회), 파티퀘스트 4종, 보스 레이드 3종, 월드보스 20단계, 길드 토벌전·대항전·레이드, 아레나(직업 상성, 전투력 5배 차이 시 즉시 결산), 10일·14일 이벤트 로테이션.

**수익 모델**: 무기·동료 가챠가 성장 본체. 멤버십 2종, **광고 제거 패키지** 있음(보상형 광고 기본 탑재). IAP 1,500~45,000원. 과금 압박 높음.

**유저 평가**: 앱스토어 4.5(2.4만). 칭찬은 원작 시스템 축약의 직관성, 서버 안정성, 낮은 초반 진입 장벽. 불만은 P2W, "같은 직업이면 다 같은 캐릭터"(선택지 없는 평면 성장), 확률 오류·품질 이슈.

**시사점**
- 베낄 것: ① 스테이지 10단위 리듬(1~9 웨이브+미니보스, 10 보스 타임어택), ② **보스별 부위 고정 드롭**("이 보스는 왜 도는가"가 자명), ③ 누적 카운트 마일스톤(누적 포획·부화 N회 보상).
- 베끼면 안 되는 것: ① 3중 강화(강화 1축 + 승급 1축이면 충분), ② 14직업 × 4차(4직업 1~3차가 상한), ③ 가챠 의존 성장(확률 오류 하나로 전액 환불).

### 2.2 스톤에이지 키우기 (넷마블엔투, 2026-03-03)

**기본 정보**
- 엔진 미확인. 2D 카툰 렌더링 캐릭터, 전열/후열 파티 전투. 원작(PC 도트)과 다른 리디자인이라 "이질적" 불만.
- 성과: 출시 8시간 앱스토어 인기 1위, 3월 2주 국내 매출 4위. Sensor Tower(2026-04-16): 누적 100만 DL, 매출 약 1,500만 달러(한국 78%). 글로벌 방치형 카테고리 DL 1위·매출 2위. **8월 주간 순위에서 사라짐**(출시 5개월).

**코어 루프**
- 무리 대 무리. **조련사 최대 6명 + 조련사당 펫 3마리 = 최대 24기 덱**, 전방/후방 배치. 조련사 스킬이 펫 스킬보다 먼저 발동.
- 니스 대륙 탐험 스테이지 + 무한소굴 + 일일 던전.
- 성장 축이 10개 이상(펫 레벨·별등급·재능 주사위·속성 진화·캐시 진화·체육관·대장간·보석·소원·토템·연구). 리뷰어가 "가짓수가 지나치게 많다"고 지적.

**직업·전직**: 없음. 조련사 6명 고정(근거리/원거리/방어/지원). 수집은 펫.

**아이템·장비**: 뽑기 3축(무기·탈것·펫, 천장 500회). 대장간 무기 강화. 부위별 슬롯·세트·스테이지 드롭 차이 미확인(장비보다 펫이 성장 본체).

**펫·수집**: 출시 펫 67종, 등급 B~SS. 마케팅은 "수백 종 포획·육성"이지만 확인된 주 획득 경로는 **뽑기 + 중복 별등급**. 필드 포획 규칙·알 부화 시스템은 미확인. 양식장(PvP 수확).

**리텐션**: 일일 던전, 무한소굴, 놀이터, 강림전(레이드), 천공의 탑 랭킹, 양식장, 메카펫 협동, 부족, 1:1 대전, **거점 쟁탈전**(서버 간 시즌, "성장 수준 무관하게 기여" 설계). 한정 이벤트 주기 짧음.

**수익 모델**: 뽑기 + **500원부터 시작하는 저가 패키지** + 상점 3종 + 멤버십 + **패스 5종(무료/유료 트랙 분리)** + 웹샵. 보상형 광고 유무 미확인. 과금 압박 높음.

**유저 평가**: 앱스토어 3.8(2.7천). 칭찬은 초반 속도·이벤트, 24기 덱 전략성, 원작 펫 향수. 불만은 IP 남용·디자인 이질감, 과금 격차·성장 콘텐츠 과다, **출시 2주 만에 공지 없는 서버 통합**·버그 무응답.

**시사점**

### 2.7 드래곤빌리지3 (하이브로, 2026-05-27)

**기본 정보**

- 로드컴플릿: "라이트코어" 포지셔닝(낮은 CPI + 높은 LTV). 결제 유저 80%가 20~30대.

**공통점과 결론**
1. **아트 밀도는 "작은 캐릭터 + 타격감"에 집중된다.** 칭찬 키워드는 타격감·이펙트·귀여움. 룡 게임은 픽셀을 버리면서까지 "부드러운 움직임과 화려한 이펙트"를 1순위로 꼽았다. 소울 스트라이크의 고해상도 최적화 불만은 역방향 경고.
2. **출시 시점 시스템 수는 적다.** 2인·7개월, "1주일 분량", PvP 일부러 제거. 시스템이 가장 많았던 픽셀 기사단은 3.0점. 유저 불만은 시스템 개수가 아니라 **성장 축 간 선택지** 부족에서 나온다.
3. **광고만으로 성공한 사례는 없다.** 성공작은 모두 광고 제거 + 소액 패스 + 성장 패키지를 병행했다. 뽑기 없이 간 게임도 성장 재화 소액 상품은 있었다.
4. **한국 비중이 낮다.** 레전드 오브 슬라임 한국 15%. 글로벌 로컬라이즈가 매출 상한을 결정한다.
5. **Flutter 사용 사례는 하나도 없었다**(확인된 엔진은 전부 Unity). 타격감·이펙트가 리뷰의 핵심인 만큼 Flame에서 파티클·히트스톱 품질을 초기에 검증하는 것이 리스크 관리 1순위.

**무리 전투는 장르 표준**이다. 오늘 결정한 무리 전투 전환은 맞다.
**직업·전직은 상위권의 필수 요소가 아니다.** 메이플·버섯커·픽셀 법사만 있고, 나머지는 "고정 소수 캐릭터 + 수집 다수"로 간다. 직업은 차별화 요소가 아니라 "선택지"를 주는 장치로 써야 하며, 메이플의 최대 불만이 "같은 직업이면 다 같은 캐릭터"였다는 점을 기억해야 한다.
**수집 = 성장이 되는 도감 보유 효과**(세나 펫, 쿠키런 도감)가 우리 기획 6장 "도감 축 영구형"과 정확히 같은 발상이며, 실제로 리텐션이 검증된 구조다.

- 2·3차 전직, 펫 전용 장비, 승급석·강화 던전, 길드·채팅, 실시간 PvP, 한정 배너식 이벤트 로테이션

## 4.0 왜 추가했는가

3장까지의 조사는 게임별(세로)로만 봤다. 조사 항목이 코어 루프, 직업·전직, 아이템·장비, 펫·수집, 리텐션, 수익 모델, 유저 평가였고, 퀘스트와 시설은 "리텐션" 한 줄에 뭉개졌다. 그 결과 언급 밀도가 이렇게 기울었다.

### 소비 층
- **대장간**: 단조석 소모. 제작할수록 숙련도/레벨 상승 → 고등급 확률 상승. 자동 제작 지원. 분해 시 강화석·골드 환급.
- **장비 강화**: **파괴·등급하락 없음, 무한 99강**, **모든 장비가 강화 단계를 공유** → 장비 교체 손실 0. 실패 시 다음 확률 상승.
- **나무몽둥이**: 망치 소모. 강화할수록 **몽둥이 길이가 실제로 길어지고** 공격력/방어력/체력/관통력 % 증가. 영상의 거리(131m→206m) 표기는 문헌 근거 미확인.
- **성장**: 골드로 파티 공용 공격력/방어력/체력. **3속성을 각 10레벨씩 올리면 다음 레벨 단계로 진행.** 탭은 훈련/유물/소울.
- **연구소**: 지식 소모. 황색/청색/적색 옵션, 최대 10레벨(2025-03 기준).
- **캐릭터 스탯**: 계정 레벨업 시 캐릭터당 6포인트, **초기화 무료**. STR=공격력, DEX=명중.

### 유저 평가

**칭찬**: 무한 강화(파괴 없음)의 안심감, 재화를 많이 뿌려 매일 체감 성장, 무과금도 진행 가능("현질 안 해도 매우어려움까지 간다"), 뽑기 체감이 표기 확률 대비 나쁘지 않음.

**불만**
1. **크래시** — 앱스토어 최신 리뷰 과반이 튕김·발열. "3분에 한 번씩 튕긴다", "몽둥이 레벨업 창에서 멈춤". 1년 넘게 미해결.
2. **편의성** — 던전 자동 진행 없음, 입장권 일괄 사용 없음, 성장 일괄 강화 없음, **영지 시간단축을 1장씩만 사용 가능**. "방치형인데 왜 이렇게 귀찮게 만들었나".
3. **이벤트 = 패키지 판매**라는 말장난. 거래 불가 게임인데 패키지가 비쌈.
4. 원작 스토리 재현 부족. **지옥 3까지만 스토리 존재**, 스테이지는 훨씬 앞까지 뚫려 지루함.
5. 서버 분리·이동 불가(2025-04 기준 41서버).

### 1인 개발자 시사점 — 층별 최저비용 구현

**① 획득 층.** 베낄 것: **재화 1종 = 소비처 1종** 규칙. 이게 "던전 6개"라는 풍부함의 정체다. 비쌀 것: 던전 6종의 개별 연출. **최저 구현**: 필드 그대로에 배경 틴트만 바꾼 "던전 모드" 1개 + 드롭 테이블 6개 + 일일 티켓. 몬스터·맵 신규 제작 0.

**② 소비 층.** 베낄 것: **파괴 없음 + 강화 단계 장비 공유.** 실패 스트레스와 "장비 바꾸면 손해" 문제를 동시에 없애는 이 게임 최고의 설계. 비쌀 것: 대장간 숙련도·확률 튜닝. **최저 구현**: 강화 레벨은 캐릭터 귀속 정수 하나, 장비는 배율만 제공. 코드 20줄.

**③ 수집 층.** 베낄 것: **미장착 보유 효과.** 잡은 몬스터 도감이 "장착 3마리 + 나머지는 보유 스탯"이 되면 포획 콘셉트와 완벽히 맞는다. 비쌀 것: 어시스터 고유 아트 수십 종. **최저 구현**: 잡은 몬스터 스프라이트 재활용, 도감 수집도 % → 전역 스탯 곡선 1개.

**④ 유도 층.** 베낄 것: **번호 붙은 단일 퀘스트 시퀀스 + 느낌표 아이콘.** 튜토리얼을 안 만들고도 순서를 잡아주는 최저비용 온보딩. 비쌀 것: 스토리 챕터 연출. **최저 구현**: `{조건, 목표수, 보상}` JSON 200줄. 목표는 기존 이벤트(처치·강화·클리어) 카운터 재사용.

**⑤ 시간 층.** 베낄 것: **파견/해독 타이머 + 가속권.** 접속 이유를 만드는 가장 싼 장치. 비쌀 것: 없음(거의 무료). **최저 구현**: `완료시각` 하나 저장, 슬롯 3개, 2시간·8시간 두 등급. 단 **가속권 일괄 사용을 반드시 넣을 것** — 이 게임 불만 1순위.

**⑥ 마을 층.** 베낄 것: 건물 레벨이 **시간 층의 처리량**을 올리는 구조(여관 레벨→임무 등급, 도서관 레벨→동시 6개). 비쌀 것: 아이소메트릭 마을 아트. **최저 구현**: 정지 배경 1장 + 건물 아이콘 4개 + 각 건물 팝업 UI. **걸어다닐 필요 없이 버튼 4개짜리 화면이면 충분.**

**가장 중요한 교훈.** 이 게임의 풍부함은 콘텐츠 양이 아니라 **재화-소비처 매핑을 20개로 쪼갠 것**이다. 전투는 하나, 필드도 하나다. 그리고 **크래시와 일괄 처리 부재**가 4.6★를 4.9★로 못 만드는 이유이므로, 1인 개발자는 그 두 가지를 처음부터 피할 수 있다.

### 층별 분석

**획득 층 — "이 콘텐츠를 왜 도는가"**
- 최강: 드빌3. 알이라는 단일 목표물에 6개 경로가 수렴하고, 경로마다 얻는 종이 달라 도감에 명시된다.
- 최저비용: 버섯커. 드롭 테이블을 전부 없애고 램프 하나로 통합. 제작비 최저, 도파민 최대.
- 목적: 목적지를 만든다. 메이플의 보스별 부위 고정 드롭이 교과서. 크럼블은 뽑기 5종 병렬이라 "무엇을 왜 뽑는가"가 흐려진 반례.

**소비 층 — 재화가 사라지는 곳**
- 최강: 픽셀 법사(12축+)·스톤에이지(10축+). 단 스톤에이지는 "가짓수가 지나치게 많다" 지적을 받고 5개월 만에 순위에서 사라졌다. 많다 ≠ 좋다.
- 최저비용: 세나·크럼블의 레벨→스킬→승급 3단 직선.
- 목적: 핵심은 축 개수가 아니라 **축마다 병목 재화가 다르게 배정됐는가**. 그래야 여러 콘텐츠를 돌 이유가 생긴다.

**수집 층 — 영구히 쌓이는 것**
- 최강: 크럼블. 획득만 하면 자동 등록 + 관계성에 따라 도감 능력치 업그레이드. 세나 펫 보유 효과와 같은 원리인데 UI가 도감이라 빈칸 채우기 동기가 얹힌다.
- 최저비용: 세나 펫 보유 효과. **신규 아트 0개, 스탯 합산 로직 한 줄.**
- 목적: 중복 드롭을 쓰레기가 아니게 만들고, 전투력 정체 구간에서 "오늘 뭔가 늘었다"를 보장한다. 메이플은 이 층이 비어 있고 "같은 직업이면 다 같은 캐릭터" 불만이 여기서 나온다.

**유도 층 — 다음 행동 지시**
- 최강: 드빌3(스토리+일일퀘+업적+도감 빈칸 4중), 세나(가이드 과제), 버섯커(초반 가이드 퀘스트).
- 최저비용: **레벨 게이트 자체를 유도로 쓰기.** 버섯커 진화 15/30/50Lv, 픽셀 법사 전직 시련 9단. 별도 퀘스트 데이터 없이 다음 마일스톤이 화면에 뜬다.
- 목적: 방치형은 유저가 스스로 목표를 세우지 않는 장르. **첫 세션 안에 1차 전직**(버섯커 30레벨) 같은 조기 대형 마일스톤이 D1의 핵심.

**시간 층 — 돌아올 이유**
- 최강: 드빌3. 부화·교배·채집이 서로 다른 주기로 돌아 접속 시각이 분산된다. 부화장 포화가 손실이라 재접속 압력이 구조적. 단 모래시계 과금 유도가 과하다는 평.
- 최저비용: 오프라인 보상 + 일일 입장 횟수. 메이플의 **열쇠 하루 3회 충전·최대 10회 누적**이 잘 만든 형태 — 하루 빠져도 손실이 0이 아니라 완충되어 이탈 유발이 적다.
- 목적: 세션을 끊고 다시 잇는다. 크럼블은 오프라인 자동진행을 빼서 이 층이 약하고 "방치형인데 손컨 강요" 불만과 짝을 이룬다.

**마을 층 — 전투 밖 화면**
- 최강: 드빌3(빌리지 건설), 버섯커(정원: 광산·연구소·재배).
- 최저비용: **안 만드는 것.** 8종 중 메이플·세나·픽셀 헌터·픽셀 법사 4종이 마을 없음이고 여기에 국내 매출 1위가 포함된다.
- 목적: 전투 정체 구간의 대체 활동 + 꾸미기 과금 지면. **없어도 매출 1위가 가능한 유일한 층.** 신규 화면·건물 아트·건설 타이머 서버 로직이 전부 필요해 비용 대비 효율이 가장 나쁘다.

## 4.3 유도 층 집중 조사

### 결론

유도 층은 이 장르에서 선택이 아니라 코어다. 한국어 웹에 이 층을 문서화한 자료가 거의 없어(공략 생태계가 티어표·쿠폰·재화 효율에 집중) 퀘스트 문구·UI 위치·레드닷 규칙은 대부분 미확인이다. 반면 **구조는 8종 전부에서 동일하게 반복된다**: 순차 가이드 미션 1트랙 + 진행도 기반 해금 + 누적 카운터 체크리스트 + 전투력 단일 숫자. **스토리는 거의 없다.**

### 퀘스트 체인 구조

**세븐나이츠 키우기가 상한선이다. 가이드 퀘스트가 2,000개를 넘는다.** 게임인사이트 리뷰: "2,000개를 초과하는 가이드 퀘스트가 연이어 제공되며, 단순 스테이지 클리어뿐 아니라 각종 콘텐츠를 오가며 완수할 때마다 뽑기권과 루비를 넉넉하게 제공한다." 즉 **퀘스트 체인이 콘텐츠 순회 동선 자체를 설계한다.** BlueStacks 초보자 조언도 "영향력은 '가이드' 퀘스트가 요구하는 수치를 우선 올려라"로, 퀘스트가 스탯 배분 우선순위까지 대행한다.

메이플 키우기 초반 전직 퀘스트 목표: **1차 슬라임 사냥 / 2차 검은 구슬 30개 수집 / 3차 분신 또는 교관과의 전투 승리**. 목표가 "N마리 처치·N개 수집·특정 적 격파" 세 형태로 수렴한다.

레전드 오브 슬라임은 퀘스트 목표가 **스탯 레벨 자체**다 — "체력 Lv 15000 달성" 형태.

**99강화 나무몽둥이**(다에리소프트 개발 / 스튜디오리코 유통, 웹툰 IP, 2025-02-05 출시): 나무위키가 퀘스트를 "유저가 잘 뚫고 나갈 수 있도록 **성장 관련 가이드 미션을 던져주는 역할**"이라 정의. 출시 직후 장비 강화 미션의 골드 요구량이 과해 **2월 7일 이틀 만에 난이도 하향**. 유도 층 난이도 곡선이 곧 초반 이탈률이라는 실증.

화면 위치는 전 게임 미확인.

### 해금 게이트

**레전드 오브 슬라임** (재구성 가능한 유일한 스케줄):

| 해금 대상 | 조건 |
|---|---|
| 더블샷 | 공격속도 Lv 200 |
| 트리플샷 | 더블샷 Lv 1001 |
| 던전 6종 | 보스 러시 → 골드 던전 → 마을 침략 → 드워프의 왕 → 돌격! 슬라임 → 비밀의 언데드방 순차 |
| 돌격! 슬라임 던전 | 어려움 6 클리어 (반지 유일 획득처) |
| 마을 침략 | 120스테이지 |

버섯커: 30레벨 1차 전직 / 50레벨 2차 / 램프 11레벨부터 2개씩 오픈 / 난이도 1~10 클리어 시 유물 해금.
세나: 무한의 탑 = 모험 2-20 클리어. 파티 슬롯 10칸이 계정 레벨마다 한 칸씩.
헌터 계열: 시련의 빌딩 50층 = 광전사 전직, 55층 = 모든 스킬 슬롯 개방.
드루와 던전: 나무위키가 "스탯 증가보다 **콘텐츠 해금을 목적으로** 레벨을 올려야 한다"고 못박음. **장비 도감 완성 → 유물 해금**, 20스테이지 이상 환생 가능.
쿠키런 크럼블: "콘텐츠 역시 편성 가능한 쿠키와 마찬가지로 **클리어한 스테이지에 따라 순차적으로 오픈**".
스톤에이지: "스테이지를 진행하면 조련사가 한 명씩 해금되는 구조".

**설계 원칙** (AFK Arena 디컨스트럭션): "Features are not unlocked by player level or other progression, only by campaign progress" — **레벨이 아니라 진행도로만 해금해야** 신규 모드 도달 시점의 팀 파워가 정확히 맞는다.

### 가이드 미션 / 업적

일일 퀘스트와 별개 트랙 존재는 확인되나 구조는 대부분 미확인. 99강화 나무몽둥이는 메인 퀘스트 + 일일 퀘스트 2트랙. 드루와 던전은 업적이 "어려움 난이도 이외의 클리어를 인정하지 않아 어려움이 암묵적으로 강제" — 업적 조건 한 줄로 플레이 스타일을 유도한 사례.

가장 구체적 체크리스트는 이세계 용병단 키우기의 칭호: 소환 2,000회 / 아레나 누적 100승 / 아레나 50연승 / 헌트 산림지대 헬 2챕터 50스테이지 클리어. **누적 카운터형 + 진도형** 두 종류를 섞어 영구 스탯으로 회수.

### 성장 목표 제시

**"약한 스탯을 지목하는 추천 패널"은 8종 어디서도 확인되지 않았다.** 대신 둘로 대체한다.
1. **전투력 단일 숫자** — 99강화 나무몽둥이는 무량대수를 넘어 `<무2>`, `<무3>` 표기까지. 크럼블은 파티 전투력 합계가 실제 최종 대미지 보정 계수로 들어감.
2. **퀘스트가 추천을 대행** — 세나의 "가이드 퀘스트가 요구하는 영향력 수치를 우선 올려라".

### 스토리

**거의 없고, 있어도 방치된다.** 드루와 던전은 스토리가 "대부분 삭제". 99강화 나무몽둥이는 웹툰 IP임에도 "지옥 3까지의 스토리만 나와 있어 너무 짧다, 스테이지는 훨씬 멀리까지 개통되어 지루함을 느끼기 쉽다"는 평가. 세나는 원작 종말 서사를 버리고 "영웅들의 소소한 일상"으로 톤 하향.

### 레드닷 설계

정량 데이터는 미확인이나 규칙은 명확하다.

- 김우진 "빨간점은 어디에 사용해야 할까": "**빨간점은 고객과 한 약속입니다.**" 좋은 예 제2의 나라("따라가면 항상 실질적 보상"), 나쁜 예 히트2("종종 아무 할 일도 없는 인터페이스에 도착") → "빨간점에 대한 신뢰가 무너져 주목도가 낮아진다".
- Braze: "If it's always there, it might as well not be there at all."
- UWA 구현 표준: **모든 비리프 노드의 레드닷은 자식 노드 집계로만 결정. 비리프 노드에 직접 개수 세팅 금지.** 가장 흔한 실패는 "초기에 레드닷 전체를 설계하지 않고 화면마다 따로 구현한 것".

### 설계 권고 — 솔로가 실제로 출시할 수 있는 최소 유도 층

**총 범위: 데이터 테이블 3개 + UI 위젯 2개 + 레드닷 트리 1개. 신규 씬 0개.**

**① 가이드 미션 1트랙, 번호 매긴 60개**
2,000개는 라이브 운영 조직의 숫자다. 솔로는 첫 3일치 = 60개면 충분. 화면에는 **항상 1개만** 보인다(완료 즉시 슬라이드 교체). 목표 문구 3형태 고정: `N층 도달` / `N종 포획` / `X를 N레벨(강)까지`.

처음 10개:
1. 몬스터 10마리 처치 · 2. 공격력 5레벨 · 3. 10층 도달 · 4. 장비 1개 착용 · 5. **몬스터 1종 포획**(도감 첫 등록) · 6. 25층 도달 · 7. 장비 +3 강화 · 8. 체력 10레벨 · 9. **골드 던전 1회 클리어** · 10. **50층 도달 → 1차 전직**

의도: 5번에서 차별화 핵심(도감), 9번에서 일일 루프, 10번에서 첫 큰 배수(전직)를 각각 첫 세션 안에 체험. Playio 기준 **코어 게임플레이 60초 이내, aha moment 90초 이내, 최초 투어 2단계 이하**를 지키려면 1~2번은 자동 완료 수준.

**② 보상: 다이아 소액 + 해금 그 자체**
1개당 다이아 10~30. 60개 총합 1,000 다이아 내외로 광고 경제를 흔들지 않는다. **10의 배수마다 실물 보상**(포획률 부스트 1시간, 강화석 묶음, 편성 슬롯 확장권). 수령은 반드시 **버튼 탭** — 이것이 레드닷 해제 조건.

**③ 표시: 화면 상단 고정 1줄 배너**
`[아이콘] 12. 30층 도달 (24/30) [이동]`. 탭하면 해당 콘텐츠로 딥링크 이동. 완료 시 `[받기]`로 바뀌고 레드닷 켜짐. 별도 퀘스트 탭은 MVP에서 만들지 않는다.

**④ 해금 게이트: 레벨이 아니라 층에만 건다**

| 층 | 해금 |
|---|---|
| 10 | 능력치 업그레이드 |
| 20 | 장비 드롭·강화 |
| 30 | 도감(포획 활성화) |
| 50 | **1차 전직** · 골드 던전 |
| 80 | 용 알 부화 |
| 100 | 펫 편성(슬롯 1) |
| 120 | 속성 던전 |
| 150 | **2차 전직** · 아레나 |
| 200 | 보스(레이드) |
| 300 | **3차 전직** · 강화 던전 |

잠긴 콘텐츠는 숨기지 말고 **회색 자물쇠 + "80층에서 해금"**으로 노출. 이것만으로 다음 목표가 생긴다.

**⑤ 성장 목표 패널 (2일차 작업)**
메인 화면 전투력 숫자를 탭하면 **기여도 분해 막대**(능력치/장비/도감/펫/전직) + 맨 아래 **"골드로 지금 살 수 있는 가장 싼 업그레이드" 1개만** 버튼. 추천 알고리즘 불필요, `min(비용)` 정렬이면 충분.

**⑥ 레드닷: 트리로, 리프에만 세팅**
루트(메인 HUD) → 탭 → 항목. 비리프는 자식 OR 집계로만. 해제 조건은 탭 진입이 아니라 **보상 수령**으로 통일. 리프 6개만: 가이드 미션 완료 / 일일 퀘스트 수령 가능 / 던전 무료 입장권 잔여 / 강화 가능(재료 충분) / 도감 성급 상승 가능 / 우편함.

**⑦ 스토리: 전직 4회 × 대사 5줄, 전면 스킵**
그 이상 만들지 않는다. 스토리를 만들어도 방치된다는 것이 99강화 나무몽둥이·드루와 던전의 실증. 그 시간을 가이드 미션 60개의 난이도 곡선 조정에 쓴다.

## 4.4 시간 층 집중 조사

조사 9종 중 공개 텍스트로 수치까지 확인된 것은 6종. 스태미나 회복 속도·파견 슬롯 수·광고 일일 상한은 인게임 UI에만 있어 다수가 미확인.

### 오프라인 보상 설계

**캡 8시간이 사실상 표준이고, 동시에 가장 큰 불만의 원천이다.**

| 게임 | 캡 | 효율 | 확장 |
|---|---|---|---|
| 버섯커 | **8시간**, 초과분 미적립 | 온라인과 유사 | 광고 시청 **+2시간**(정액) |
| 크럼블 | **8시간** | 미확인 | 스위트 블레싱 Lv.2 +1시간, 유료 팩 |
| 픽셀 헌터 | **8시간** | 오프 분당 180마리 vs 온라인 600~1000 (**18~30%**) | 미확인 |
| 픽셀 법사 | **24시간**(10분 이상부터) | 미확인 | **광고 2배** |
| 메이플 | **8h → 24h**(2026-02-12 패치) | 오프 51마리/분(멤버십 76) vs 온라인 92~113 → **45~55%** | 회원권 +12h = 최대 36h. **24시간 내 미수령 시 만료** |
| 세나 | 미확인 | **오프라인이 온라인 대비 1.3배 유리**(역발상) | 부스터 쿠폰 4h/24h |

메이플은 앱 완전 종료 후 5분 경과해야 오프라인 판정. **백그라운드가 최악**(사냥도 안 되고 오프라인도 안 쌓임). 업계 가이드 권장치는 **캡 8~24h, 오프라인 획득량은 활성 플레이의 30~50%, 광고 +100%**.

### 파견 / 채집 구조

**대형 4종(버섯커·크럼블·세나·스톤에이지)에서 슬롯형 파견은 하나도 확인되지 않았다.** 한국 키우기류의 표준 문법이 아니다(단, "없음" 확정이 아니라 확인 실패).

- **픽셀 법사 — 유일하게 수치가 확정된 파견**: 탐험 슬롯 1개당 **하루 1회**, **고정 3시간** 소모, 탐험 등급 4단계(1~4성), **슬롯은 보유 펫 성급에 따라 해금**, 보석으로 하루 최대 15회 리스트 갱신. **슬롯 5개.**
- **드빌3 채집은 파견 타이머가 아니다.** **피로도를 소모해 즉시 출격**하는 반복 콘텐츠, 회당 소요 초 단위. 지역 7곳 각 2속성. 보상은 "데려가는 드래곤들의 전투력 총합에 따라 최대 15단계".
- **99강화 나무몽둥이**: 스토어 문구는 "영지에서 모험가를 파견하고, 마법 스크롤을 해독하며"까지만 확인. 여관 파견 1~2시간·도서관 해독 8시간·연구소 노드 수는 공개 자료로 미확인. 다만 공략의 운용 원칙은 확인됨: "시간이 오래 걸리는 작업은 잠자기 전, 짧은 작업은 플레이 중 반복" → **장(8h) + 단(1~2h) 타이머 2쌍**이 골격.

### 타이머 단축의 수익화

**광고는 "보상 2배"보다 ① 대기시간 정액 단축 ② 입장권 추가에 더 많이 붙는다.**

- 버섯커: **램프 레벨업 광고 1회당 30분 단축**, 오프라인 +2시간, 일일 던전 열쇠 추가, 15연 가챠 3회 추가
- 메이플: **빠른 사냥**(즉시 지급, 1회마다 +5마리 누적, 최대 3,000마리) 무료 1회/일 + 광고 +1회, 상점 광고 레드 다이아 1,000개/일, 여정의 보물 주간 가속 광고 1회로 +20~30%
- 픽셀 헌터: **소환당 광고 3회씩**, 데일리 무료보석 하루 3번 → 15,000보석, **던전 추가 입장(VIP 레벨만큼)**
- 픽셀 법사: 오프라인 2배, 월드보스 +3회, "광고 보상은 **하루 최대 3회**까지"
- 유료 단축: 드빌3 모래시계는 교배시간 단축(개당 단축량 미확인). 메이플은 시간 가속 티켓 + 길드 연구 블루 다이아 200개

### 연구 · 생산 트리

노드 수를 명시한 자료는 **어느 게임에서도 못 찾음**(전부 미확인). 확인된 것은 구조와 대기 시간의 규모.

- **메이플이 최악의 사례**: 엘리트 소환 레벨업 / 용사의 힘 / 스킬 마스터리 / 여정의 발자취가 전부 대기 타이머이고, 유저 건의글 원문 기준 "**스킬 하나, 옵션 하나를 해금하기 위해 80시간, 100시간씩 기다리는 것**". 프리미엄 회원권이 요구 시간 10~15% 감소를 판매.
- 크럼블: 연구실 + 일일 제한 재화 "연구석". 유저 반응 "연구석 없으니까 하루 손해보는 기분 / 내 연구실 먼지 날린다"
- 스톤에이지: 연구 항목 5종(이빨/개체값 조련석/스태미나/명중률/치명타율)만 확인

### 누적 저장 (스택)

**저장을 허용하는 게임이 명확히 더 좋은 평가를 받는다.** 메이플 성장 던전 열쇠 3→10 저장이 대표 사례. 드빌3는 레이드 티켓 보유 상한을 5→10장으로 상향. 반대로 픽셀 법사 소탕권(상한 3, 초과 미지급)과 낚시 살림망(1,000마리 상한 후 정지 — "방치해두고 장시간 일다니는 분들은 꽉차서 어느순간 낚시가 멈춰 있더라")은 손실 불만을 만든다.

### 소규모 팀 최소 구성

| 층 | 픽셀 헌터(2인, 50만+ DL) | 픽셀 법사(1인, 10만+ DL) |
|---|---|---|
| 오프라인 누적 | 8시간 | **24시간 + 광고 2배** |
| 자정 리셋 티켓 | 던전 4종 + 광고 추가 | 소탕권 3장 + 광고 추가 |
| 시간 회복 재화 | 없음 | 미궁 티켓 **24분마다** |
| 파견 | **없음/미확인** | 펫 탐험 5슬롯 × 3h × 1일 1회 (**후기 추가**) |
| 주간 경쟁 | 길드작·칭호·투기장 | 월드보스(화~일)·레이드·게이트 |

**출시 시점 최소 구성은 3개: ① 오프라인 누적 캡 ② 자정 리셋 입장권 ③ 일일/주간 임무.** 2인 팀은 3년 넘게 파견 없이 운영했고, 1인 팀도 파견을 나중에 붙였다.

### 설계 함정 — "숙제"라는 단어

**"숙제"가 리뷰에 등장하는 순간이 이탈 직전 신호다.** 예외 없이 부정 맥락이고 영어권 "chore / second job"과 정확히 대응한다.

- "어느순간 매일 숙제하러 접속하는 생각이 들었음… 계속해야되나 고민하다 그냥 때려치기로 결정" (AFK 아레나 3점)
- "하루에 이룰 수 있는 성장 한계치가 있어서 매일 어느정도 게임을 하지 않으면 안된다는 강박관념… 게임이 숙제가 되버리는 것이 싫어서 그만둡니다" (AFK: 새로운 여정 4점)
- "퇴근하고 집에와서 숙제5분컷하고 끄는게 다임" (메키 갤)
- **캡 불만의 기준선은 수면 시간**: "방치하라며... 왜 오프보상 상한 고작 8시간?", "거의 4시간에 한번씩은 접속해야 게임 돌아갑니다"(버섯커)
- **고정 리셋 시각이 캡보다 더 나쁘다**: "오전 9시 기준 리셋인데… 기계처럼 8~9시 사이에 20분 정도 투자해야되는 건... 하루의 시작을 게임으로 시작하게 만듭니다"
- **광고 개수 = 타이머 개수로 환산된다**: "광고제거 없이는 하루에 50번 정도 광고 봐야한다고 생각하면 됨"(세나), "숙제 광고 30분~40분임"(픽셀 법사)
- **파견 자체가 이탈 사유가 된 사례**: "파티 원정 주기가 점점 짧아지면서 유저들의 많은 피로감을 유발… 파티 원정 때문에 접는 유저들이 상당히 많아졌다"(AFK 아레나)
- 넥슨 스스로 "부족한 편의 기능으로 인한 피로감"을 인정하고 3개월치 결제를 전액 환불
- 영어권: "Timed quests generally feel like an obligation and not a choice. That instantly removes the fun."

### 설계 권고 — 1인 개발이 감당하는 최소 시간 층

현재 프로젝트는 오프라인 보상, 일일 던전, 아레나, 레이드를 이미 갖고 있다. **새 시스템을 더할 게 아니라, 있는 것의 파라미터를 고치고 알 타이머 하나만 추가하는 것이 정답이다.**

**① 오프라인 캡 8h → 12h, 효율 50% 유지.** 8시간은 전 게임에서 가장 강한 반발을 산 수치다. 12h면 자고 일어나 받아도 손실이 없고 하루 2회(기상/퇴근) 복귀 리듬이 만들어진다. **광고 제거 구독에 +12h(총 24h)를 붙여 상한 자체를 상품화**한다. **미수령 만료는 두지 말 것** — 메이플의 24h 만료는 강박을 만든다.

**② 용 알 부화기 = 슬롯 3개.** 등급별 **30분 / 2시간 / 6시간** 3단계, **광고 1회당 30분 단축, 1일 5회**(버섯커 램프 방식). 슬롯 확장은 다이아로 팔되 최대 5칸까지만.

**③ 파견은 "용 탐험" 1개만, 슬롯 3개 × 4시간.** 이미 있는 지역 10개를 재활용해 보상 등급을 **파견 몬스터 전투력 합계 5단계**로 결정(드빌3 15단계는 과함). **하루 1회 제한은 걸지 말 것** — 픽셀 법사 유저가 정확히 그 지점에 불만. 4시간 × 3슬롯이면 하루 3~4회 복귀가 나온다. **이것이 알 획득 경로 3개 중 하나를 겸하므로 시스템이 하나 늘지 않고 통합된다.**

**④ 일일 입장권에 누적 저장 도입.** 골드 던전·속성 던전 각 3회를 **최대 9회 저장**, 아레나 5회는 **최대 15회 저장**. 메이플의 "**실패 시 열쇠 미소모, 성공 시 1개 반환**"을 그대로 베낄 것 — 입장권을 "숙제"가 아니라 "실패 허용 횟수"로 바꾸는 장치다.

**⑤ 광고 배치는 현재 6종에서 늘리지 말 것.** 유저는 광고 개수를 "하루 몇 분"으로 환산한다. "무료 다이아 3회"를 1회로 줄이고 오프라인 2배와 부화 단축에 집중. 리셋은 **전부 자정 하나로 통일**.

**⑥ 하루 총 숙제 시간 목표: 10분 이내.** 오프라인 수령(광고 1개) → 탐험 3슬롯 재출발 → 던전 소탕 → 아레나 5회. 이게 전부여야 한다.

### 절대 추가하면 안 되는 타이머

1. **스태미나/피로도.** 입장권으로 충분하고, 광고 BM과 정면 충돌(회복을 팔 유료 재화가 없음).
2. **연구소/연구 트리.** 메이플의 "스킬 하나 해금에 80시간, 100시간"이 환불 사태의 한 축. 도감 패시브가 이미 같은 역할(느린 영구 성장)을 하므로 중복.
3. **제작 큐 / 생산 건물.** 자동화까지 붙일 여력이 없다면 넣지 말 것.
4. **요일 던전.** 속성 던전이 "그날의 속성"으로 같은 역할. 놓치면 일주일 손해라 강박만 늘린다.
5. **파티 원정처럼 주기가 짧고 여러 명이 얽히는 타이머.** AFK 아레나의 대표 이탈 사유.
6. **일일 강등 페널티**(세나 결투장). 접속 안 하면 점수가 깎이는 구조는 "숙제"를 "빚"으로 만든다.

**결론: 추가하는 시간 층은 "용 탐험 3슬롯 × 4시간" 하나뿐이고, 나머지는 캡을 12h로 올리고 입장권에 저장을 붙이는 파라미터 변경이다.** 이 조합이면 복귀 지점이 하루 3~4회 생기면서도 관리할 타이머는 **오프라인·부화·탐험 3개**로 유지된다. 불만이 가장 적은 픽셀 법사(1인, 평점 4.8)의 시간 층도 실질적으로 이 규모다.

## 4.5 우리 프로젝트 진단과 결론

### 층별 두께 진단

| 층 | 우리 현재 | 시스템 수 | 진단 |
|---|---|---|---|
| 획득 | 필드 사냥, 포획, 오프라인 보상, 골드 던전(계획), 스테이지 드롭(계획) | 5 | 얇음 |
| 소비 | 능력치 업그레이드 5종, 전생·영혼 상점, 전직 | 3 | 얇음 |
| 수집 | 도감 100종 + 패시브, 지역 완성 보너스 | 2 | **두꺼움, 우리 강점** |
| 유도 | 없음 | **0** | **비어 있음** |
| 시간 | 오프라인 보상 | 1 | 얇음 |
| 마을 | 없음 | 0 | 비어 있음 |
| **합계** | | **11** | 픽셀 헌터 22, 픽셀 법사 30 |

목표는 **22~24**다. 픽셀 헌터(2인 팀, 2년 매출 100억)가 22이므로 그 선이 1인 개발의 현실적 상한이다. 30은 픽셀 법사의 1.5년 라이브 누적 결과라 출시 목표가 아니다.

### 핵심 결론 다섯

**① 풍성함은 콘텐츠 양이 아니라 재화-소비처 매핑의 개수다.**
99강화 나무몽둥이는 전투도 하나, 필드도 하나인데 재화-소비처 쌍이 23개다. 던전이 여섯 개인 이유는 콘텐츠가 여섯 개라서가 아니라 **소비처가 여섯 개**이기 때문이다. 층 비교에서도 같은 결론이 나왔다. "핵심은 축 개수가 아니라 축마다 병목 재화가 다르게 배정됐는가."

우리가 늘려야 할 것은 전투 콘텐츠가 아니라 매핑이다. 현재 재화는 골드·영혼·다이아·아레나 코인 4종이다. 여기에 강화석·스킬북·알·탐험 보상을 더해 **8~10쌍**으로 만든다.

**② 마을 층은 만들지 않는다.**
8종 중 메이플·세나·픽셀 헌터·픽셀 법사 4종이 마을 없음이고 여기에 국내 매출 1위가 포함된다. 신규 화면·건물 아트·건설 타이머 서버 로직이 전부 필요해 비용 대비 효율이 가장 나쁘다. **없어도 매출 1위가 가능한 유일한 층이다.** 시간 층 콘텐츠는 편성 탭 안에 넣는다.

**③ 유도 층이 최우선이고 가장 싸다.**
비어 있고, 구현은 JSON 200줄이다. 세나는 가이드 퀘스트가 2,000개를 넘고 그것이 콘텐츠 순회 동선 자체를 설계한다. 99강화는 초반 퀘스트 난이도가 과해 **출시 이틀 만에 하향 패치**했다. 유도 층의 난이도 곡선이 곧 초반 이탈률이다.

- 번호 붙은 **단일 퀘스트 시퀀스 60개**(첫 3일치). 화면 상단 1줄 배너에 항상 1개만
- 목표 문구 3형태 고정: `N층 도달` / `N종 포획` / `X를 N레벨까지`
- **느낌표 뱃지**가 튜토리얼을 대신한다. 레드닷은 트리 구조, 비리프 직접 세팅 금지, 해제 조건은 탭 진입이 아니라 **보상 수령**
- 해금은 레벨이 아니라 **층(진행도)에만** 건다(AFK Arena 원칙)
- 잠긴 콘텐츠는 숨기지 말고 **회색 자물쇠 + "80층에서 해금"**으로 노출. 99강화가 30분 안에 시스템 20개를 다 보여주는 것과 같은 효과를 내면서 순서는 잡힌다

**층 해금표**

| 층 | 해금 |
|---|---|
| 10 | 능력치 업그레이드 |
| 20 | 장비 드롭·강화 |
| 30 | 도감(포획 활성화) |
| 50 | **1차 전직** · 골드 던전 |
| 80 | 용 알 부화 |
| 100 | 펫 편성 |
| 120 | 속성 던전 |
| 150 | 2차 전직 · 아레나 |
| 200 | 레이드 |
| 300 | 3차 전직 · 강화 던전 |

**④ 시간 층은 파라미터 변경 + 시스템 하나만 추가한다.**
소규모 팀 둘 다 출시 시점엔 오프라인 보상 하나뿐이었다. "숙제"라는 단어가 리뷰에 등장하면 이탈 직전 신호다.

- 오프라인 캡 **8h → 12h**, 효율 50% 유지. 광고 제거 구독에 +12h를 붙여 상한을 상품화. **미수령 만료 없음**
- **용 알 부화 슬롯 3개**, 등급별 30분·2시간·6시간, 광고 1회당 30분 단축(1일 5회)
- **용 탐험 슬롯 3개 × 4시간.** 기존 지역 10개 재활용, 보상은 파견 몬스터 전투력 합계 5단계. **하루 1회 제한 금지.** 이것이 알 획득 경로 하나를 겸하므로 시스템이 늘지 않고 통합된다
- 일일 입장권에 **누적 저장**(던전 3회 → 최대 9회, 아레나 5회 → 최대 15회). 메이플의 "실패 시 미소모, 성공 시 1개 반환"을 그대로
- 리셋은 전부 **자정 하나로 통일**. 하루 숙제 총량 **10분 이내**
- **금지**: 스태미나·피로도, 연구 트리, 제작 큐, 요일 던전, 파티 원정, 일일 강등 페널티

**⑤ 광고 중심 BM이 곧 차별화다.**
99강화는 보상형 광고를 의도적으로 약하게 만들어 **11,000원 광고제거권을 팔기 위한 마찰**로 썼다. 유저 리뷰가 "그 흔한 광고 보고 얻는 광고형 버프도 없음"이다. 광고 중심으로 가는 우리는 **정확히 반대로** 하면 된다.

저 게임이 유료로 잠근 자리를 전부 광고 리워드로 연다. 가속, 던전 입장권, 방치 배수, 부화·탐험 단축. 단 광고 위치는 6종을 넘기지 않는다. 유저는 광고 개수를 "하루 몇 분"으로 환산한다.

### 시스템 22~24개로 가는 증분

| 층 | 추가 | 증분 |
|---|---|---|
| 획득 | 속성 던전, 장비 던전, 스킬북 보스 드롭, 알 탐험 보상, 광고 리워드 | +5 |
| 소비 | 장비 강화, 장비 분해, 스킬 강화 | +3 |
| 수집 | 미장착 보유 효과 명시, 칭호·업적 | +1 |
| 유도 | 퀘스트 시퀀스, 느낌표 뱃지, 층 해금표 | +3 |
| 시간 | 알 부화, 용 탐험 | +2 |
| 마을 | 없음 | 0 |
| **합계** | | **+14 → 25** |

던전 네 종은 **필드 씬에 배경 색조만 바꾼 던전 모드 하나**로 만들고, 종류는 `{입장 재화, 드롭 테이블, 웨이브 수}` 데이터로 분기한다. 신규 아트 제작은 0이다.

### 바로 가져올 설계 세 개

1. **장비 강화에 파괴가 없고 강화 단계를 모든 장비가 공유한다.** 실패 스트레스와 "장비 바꾸면 손해"를 동시에 없앤다. 강화 레벨은 캐릭터에 귀속된 정수 하나. 코드 20줄
2. **미장착 보유 효과.** 잡은 몬스터는 3마리 출전, 나머지는 도감 수집도로 상시 스탯. 우리 포획 콘셉트와 완벽히 맞고 신규 아트가 0이다
3. **계단식 게이트.** 99강화의 "3속성을 각 10레벨씩 올리면 다음 단계로 진행"은 숫자 하나로 리듬을 만드는 무료 트릭이다

### 피해야 할 것

99강화는 평점 4.6에서 멈췄다. 이유가 둘이고 우리는 처음부터 피할 수 있다.

- **크래시** — 앱스토어 최신 리뷰 과반이 튕김·발열. 출시 1년 반이 지나도 미해결
- **일괄 처리 부재** — 던전 자동 진행 없음, 입장권 일괄 사용 없음, 성장 일괄 강화 없음, 시간 단축권을 한 장씩만 사용. "방치형인데 왜 이렇게 귀찮게 만들었나"가 반복 불만

**일괄 처리는 나중에 붙이는 편의 기능이 아니라 처음부터 넣는 요구사항이다.**

### 서브프로젝트 순서 갱신

3.5절의 순서를 이 결론으로 대체한다.

1. **아트 파이프라인** (진행 중, 스파이크 게이트 판정 대기)
2. **무리 전투 엔진** — 다중 타깃, 서버 판정
3. **획득·소비 층** — 드랍 테이블, 던전 모드, 장비 강화·분해. 재화-소비처 매핑 8~10쌍 확정
4. **유도 층** — 퀘스트 60개, 느낌표 뱃지, 층 해금표, 레드닷 트리
5. **직업·전직 1차 + 스킬** — 전직이 유도와 성장을 겸한다
6. **알·펫 + 시간 층** — 부화 3슬롯, 용 탐험 3슬롯, 오프라인 캡 12h
7. **BM 상품 구성** — 광고 제거 영구, 시즌패스, 소액 패키지
8. **마일스톤 재산정**

유도 층이 3번 뒤로 온 이유는 퀘스트 목표가 획득·소비 시스템을 가리켜야 하기 때문이다. 획득·소비가 없으면 쓸 퀘스트가 "N층 도달" 하나뿐이다.

### 직접 확인해야 할 공백

웹으로 확인 못 한 것. 해당 게임을 설치해 30분 플레이하면 대부분 답이 나온다.

- 99강화: 퀘스트 1~25 항목명, 시스템별 정확한 해금 레벨, 여관 파견 슬롯 수, 도서관 해독 시간·슬롯 해금 레벨, 연구소 노드 트리 수치, 던전별 일일 입장 횟수, 룰렛 확률표 원문
- 픽셀 헌터·픽셀 법사: 일일 입장 횟수, 탐험 소요 시간, 도감 보너스 수치, 광고 배치 횟수, 퀘스트 화면 위치
- 전 게임 공통: 퀘스트 처음 10개 문구, 레드닷 사용 범위, 2026년 9월 현재 매출 순위
