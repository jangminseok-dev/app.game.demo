## 왜 필드 포획인가

키우기 장르 상위 게임들은 전부 뽑기로 수집한다. 필드 포획을 가진 게임이 없다.
강해진 뒤에도 낮은 스테이지에 돌아갈 이유가 생기고, 새 콘텐츠 없이도 플레이 시간이 늘어난다.

대신 장르의 주 수익원(뽑기)을 포기하는 선택이라, 수익은 리워드 광고와
광고 제거 월정액으로 만든다.
</div>

<div class="cn-card cn-bg-plain cn-body" markdown="1">
## 어떻게 만드나

| 클라이언트 | Flutter (Android · iOS), Riverpod |
| 서버 | Python · FastAPI · PostgreSQL, 헥사고날 + 허브-스포크 |
| 배포 | AWS (무료 범위에서 시작) |
| 멀티 | 비동기 — 아레나(서버 판정) · 공용 레이드 보스 · 주간 랭킹 |
| 개발 | 1인, 맥 단독 환경 |

수치는 코드가 아니라 서버 마스터 데이터에 두어 앱 업데이트 없이 밸런스를 고친다.
</div>
